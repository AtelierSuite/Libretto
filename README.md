# Libretto

Word processor that opens and saves Word documents, Markdown, plain text, and source code, and opens Pages documents to share as Word documents.

- **Libretto** is the iOS and iPadOS app, in `Libretto`.
- **Libretto for Mac** is the native AppKit app, in `LibrettoMac`.
- **LibrettoEngine** (`com.tsubuzaki.Libretto.Engine`) is the framework both build on: the document model, reading and writing every file format, and laying documents out in pages and drawing them, in `LibrettoEngine`.
